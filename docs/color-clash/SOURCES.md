# Kaynak ve ürün kararları

Erişim tarihi: 2026-10-03.

Kuralların karşılaştırma kaynağı Mattel'in yayımladığı klasik kart eşleştirme oyunu talimatlarıdır:

- https://service.mattel.com/instruction_sheets/10020-SN70_G1_4XN_IS_Uno.pdf
- https://service.mattel.com/instruction_sheets/41001-0925-2L.pdf
- https://shop.mattel.com/pages/games-uno-braille-rules

Bu kaynaklar 7 kart dağıtımı, renk/sayı/sembol eşleşmesi, çekilen kartı aynı tur oynama, özel kart etkileri, Draw Four kısıtı ve itirazı, tek kart çağrısı, puan değerleri ve 500 puan hedefini doğrulamak için kullanıldı.

Color Clash bağımsız ürün adıdır. Referans oyunun adı, logosu, kart yüzü/arkası düzeni, yazı tipi, renk tonu kombinasyonu, sesleri, animasyonları, mağaza metni veya ekran yerleşimi kopyalanmaz. Genel kart eşleştirme davranışı kendi isimleri ve özgün görselleriyle uygulanır.

## Color Clash terimleri

| Motor adı | Oyuncuya gösterilecek ad |
|---|---|
| NUMBER | Number |
| SKIP | Block |
| REVERSE | Flip |
| DRAW_TWO | Draw 2 |
| WILD | Color Shift |
| WILD_DRAW_FOUR | Clash 4 |
| UNO call equivalent | Clash! |

Kart ikonları için metin yerine özgün geometrik semboller kullanılabilir; erişilebilirlik etiketi her zaman açık yazılmalıdır.
